# AuctionHouse – Online Auction Platform

## Project Overview
AuctionHouse is a responsive online auction website where users can explore products, view auctions, and place simulated bids.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Responsive design for laptop, tablet, and mobile
- Product search and filtering
- Auction countdown timers
- Simulated bidding system
- Bid history
- User registration and login demo
- Watchlist
- Bidder dashboard
- Seller dashboard
- Contact form
- Dark mode

## Project Files
- `index.html` – Website structure
- `style.css` – Website styling
- `script.js` – Website functionality

## Note
This is a frontend demonstration project. Registration, login, bidding, and contact form features are simulated using JavaScript and browser storage. No backend or real payment processing is connected.
